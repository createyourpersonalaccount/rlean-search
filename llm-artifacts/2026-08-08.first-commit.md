| **Cache** | XML index (default `.rlean-search/index.xml`) for one-shot runs |
| **Daemon** | Tokio TCP multi-client; JSONL↔JSONL, XML↔XML |
| **Speed** | In-memory inverted index by head symbol / operators |

## Usage

```bash
cd rlean-search
cargo build --release

# Index a Lake package
./target/release/rlean-search index path/to/Mathlib -o .rlean-search/index.xml

# One-shot search (uses cache if present)
./target/release/rlean-search search '_ + _ = 0' -p path/to/pkg
./target/release/rlean-search search '?a - ?a = 0' -p path/to/pkg
./target/release/rlean-search search '|- tsum _ = _ * tsum _' -p path/to/pkg --format jsonl

# Daemon
./target/release/rlean-search daemon --bind 127.0.0.1:7878 path/to/pkg
./target/release/rlean-search query --pattern '_ + 0 = _'
./target/release/rlean-search query --xml --pattern '?a - ?a = 0'
```

## Layout

- `src/parser/` — type + declaration parsers  
- `src/search.rs` — hole/named-hole/turnstile matching  
- `src/index.rs` — inverted index  
- `src/lake.rs` — Lake layout  
- `src/daemon.rs` + `src/protocol.rs` — Tokio daemon + JSONL/XML  
- `src/xml/` — index cache codec  
- `tests/fixtures/` — demo Lake package + corpus + real Init Nat file  

Type coverage is a practical fragment (binders, arrows/Pi, apps, common ops, quantifiers, sorts, holes). Richer Lean syntax may be stored as `raw` nodes so declarations stay searchable.
