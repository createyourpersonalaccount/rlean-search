# rlean-search

Fast type-aware search over **Lean 4** `theorem`, `lemma`, and `axiom`
declarations. Vibe-coded with Grok Build.

- The repository is available at https://github.com/createyourpersonalaccount/rlean-search.
- The manual is available online at
  https://createyourpersonalaccount.github.io/rlean-search and in the
  source code at [manual/index.adoc](manual/index.adoc).
